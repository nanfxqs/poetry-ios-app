# 阅读布局原型（临时）

目的：比较正文优先的诗词阅读页如何保留情景，同时避免独立大图抢占空间或图文重叠。

运行：在本目录执行 `python3 -m http.server 8766 --bind 127.0.0.1`，打开 `http://127.0.0.1:8766/?variant=D`。

四种方案通过 `?variant=A|B|C|D`、底部箭头或键盘左右键切换。

- A：画面在上。
- B：图文并置。
- C：画面铺底。
- D：页边入景。

用户当前选择 D，A 保留备选。用户认为 A 独立图片区占屏，C 图文叠加显得混乱；D 把图缩入页眉一角并淡出，正文保留统一底色。该选择是本轮讨论方向，不是最终视觉稿验收。

边界：单页 HTML，只演示阅读构图、内存收藏、无音频的声音开关和说明展开。底部导航为结构示意。山水为程序绘制的占位图，不是历史地点复原。正文与具体来源链接见页面。刷新清空操作状态。不包含 SwiftUI 实现、真实音频或后端。
