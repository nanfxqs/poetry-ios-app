# 诗词页边画面与轻环境声来源

日期：2026-09-05。用户方向：静态页边画面、复用环境声、无循环视觉动效。本轮只核实来源与规则，未下载、试听、筛选单件作品或制作素材；下方资产表是建议清单。

## 三个来源足够启动

| 来源 | 获取方法 | 许可边界 |
| --- | --- | --- |
| [Smithsonian Open Access](https://www.si.edu/openaccess) | 搜索中国山水、花鸟、竹、月夜题材，进入具体藏品页，确认图像的 CC0 标识再使用开放图像下载入口。 | 官方允许对明确标为 CC0 的开放资产使用、改编与分享；部分藏品只有元数据开放，不能把元数据 CC0 推及其图片，也不能把全站当成 CC0。[官方 FAQ](https://www.si.edu/openaccess/faq) |
| [Wikimedia Commons](https://commons.wikimedia.org/) | 从分类或关键词找到文件，打开 `File:` 描述页核对来源、作者和许可，获取原文件。适合补充风景、植物与古画。 | 每个文件单独核实；CC BY 需署名，CC BY-SA 等还涉及改作许可条件。首版建议优先明确公有领域或 CC0 文件，保留原始文件页链接。[官方复用指南](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia) |
| [Freesound](https://freesound.org/) | 搜索 rain、stream、wind leaves、night insects，在许可筛选中选择 CC0，并在声音详情页再次核实；按网站下载流程获取文件，下载可能需要账户。 | 平台同时存在 CC0、CC BY、CC BY-NC 及部分旧许可，不是全站 CC0。官方 FAQ 说明搜索页有许可过滤，且“Free Cultural Works”包含 CC BY 与 CC0，不能把这个组合选项误当成仅 CC0。[官方 FAQ](https://freesound.org/help/faq/) |

## 首版建议资产清单

| 资产 | 场景 | 构图或听感要求 |
| --- | --- | --- |
| 静态「山水远景」 | 江行、远游、登临 | 下缘或底角远山与水面，中央大面积留白，避免地形细节压住正文。 |
| 静态「月与夜空」 | 怀人、思乡、静夜 | 上角小月轮，深浅柔和变化；不添加闪烁星点。 |
| 静态「枝叶花影」 | 春意、惜别、时序 | 仅一侧探入竹叶、柳枝或花枝；统一细节密度。 |
| 静态「岸线孤舟」 | 江湖、漂泊、独处 | 低位岸线加很小的舟影，留出完整阅读列。 |
| 环境声「细雨」 | 雨夜、闲居 | 平稳轻雨，避开突然雷声及近距离滴答尖峰。 |
| 环境声「缓水」 | 江行、溪边 | 轻水流或岸边水声，避开大浪和强低频。 |
| 环境声「叶间风」 | 山居、竹林 | 柔和树叶摩擦，避免录音风噪扑麦。 |
| 环境声「夜虫」 | 夏夜、静夜 | 稀疏、低强度，避免尖锐持续蝉鸣。 |

以上四种图像和四类声音是通用的体验资产，不表示准确还原某首诗的创作现场。通过意象与情绪人工匹配，避免用音乐自动推断诗词情感。

## 交给后续素材选择的约束

建议每件资产记录原作品/声音标题、作者、文件页 URL、准确许可及版本、获取日期与裁剪/调色/音量处理情况；在 App 的素材说明中集中展示必要署名。素材许可与原始文件一起留存，避免日后只剩一张无来源图片。

页边图裁剪后统一色调与留白，不给每首诗塞一幅完整画作。声音默认关闭，由用户主动打开；同一时间只播放一种环境声，提供明确停止入口。离线承诺只覆盖随包或下载完成的声音。声音是否循环播放仍是后续播放策略，不能由“无循环视觉动效”推定。

本轮未对单个文件完成授权、视觉适配或试听验收。后续只需从上述来源选出各类少量候选，核验文件页后再下载与处理，不必先扩展为大素材库。
