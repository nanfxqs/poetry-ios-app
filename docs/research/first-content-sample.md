# 首批内容样本：唐诗四位候选的有界核查

核查日期：2026-09-05。目的仅是验证李白、杜甫、王维、孟浩然能否形成小规模“人—地—诗”入口，不是最终选人或完整编年。证据采用诗作原文的公开转录与教育机构版本；本次没有核定写作年份、历史坐标或会面行程。

## 六个可讨论的例子

| 作品与原文来源 | 原文直接支持的关联 | 适合的展示与证据边界 |
| --- | --- | --- |
| 李白《黄鹤楼送孟浩然之广陵》：[香港教育局参考版本](https://cd.edb.gov.hk/chi/resource/ncs/download/js_list/JS_huanghelousongmenghaoran.pdf)；[维基文库版本](https://zh.wikisource.org/zh/%E9%BB%83%E9%B6%B4%E6%A8%93%E9%80%81%E5%AD%9F%E6%B5%A9%E7%84%B6%E4%B9%8B%E5%BB%A3%E9%99%B5) | 题名明确送别对象为孟浩然，正文提及黄鹤楼、扬州和长江 | 可画“诗中的送别方向”并连接李白与孟浩然。不能把路线当逐站实测行程，不能仅据诗文补写具体年份、会面过程或执笔坐标 |
| 李白《赠孟浩然》：[原文及《全唐诗》卷168入口](https://zh.wikisource.org/wiki/%E8%B4%88%E5%AD%9F%E6%B5%A9%E7%84%B6) | 题名明确赠诗对象，诗中表达敬慕 | 可将关系标为“有赠诗／敬慕”，展示表达情感的诗句；不能由“赠”字推断当面赠送或某次会面。诗中“高山”等表达也不宜地理编码 |
| 杜甫《春日忆李白》：[原文](https://zh.wikisource.org/zh-hant/%E6%98%A5%E6%97%A5%E5%BF%86%E6%9D%8E%E7%99%BD) | 题名和正文直接支持对李白的思念与诗才赞赏，正文出现渭北、江东 | 可做“隔地怀人”体验与“有怀人诗”关系。区域词不等于精确坐标；不能据此确定当日双方位置或新建具体会面事件 |
| 王维《送元二使安西》：[原文](https://zh.wikisource.org/wiki/%E9%80%81%E5%85%83%E4%BA%8C%E4%BD%BF%E5%AE%89%E8%A5%BF) | 题名有元二、安西；正文出现渭城、阳关和劝酒送别情境 | 适合区分送别场景与远行方向；阳关、安西不能标成王维的写作地。元二的完整身份和行程未核实，不补造人物履历 |
| 孟浩然《留别王侍御维》（常见题名《留别王维》）：[《全唐诗》卷160原文](https://zh.wikisource.org/wiki/%E5%85%A8%E5%94%90%E8%A9%A9/%E5%8D%B7160#留別王侍御維) | 题名点明王维，正文写故人、知音和惜别 | 为孟浩然—王维提供明确的“有留别诗”连线。正文不具名地点；“故园”不能自动落到具体住宅坐标，也未据此核定送别时间 |
| 孟浩然《过故人庄》：[原文及《全唐诗》卷160入口](https://zh.wikisource.org/wiki/%E9%81%8E%E6%95%85%E4%BA%BA%E8%8E%8A) | 明确有故人邀至田家的叙事情境，正文有田园景象和重阳再访之约 | 是很好的“不强行连图”样本：故人未具名、村庄未定位。本次不为它创建具名人物关系或地点钉；可用田园、相聚等经过编辑确认的主题入口 |

## 能支持怎样的小样本

从这些诗题与诗文可以建立一条“有作品证据的关联链”：杜甫 → 李白 → 孟浩然 → 王维。箭头在这里分别表示怀人、赠诗或留别，**不表示同一种社会关系，更不表示四人共同会面**。它可以用来验证点击关系后是否能读到具体作品依据。

这组样本已经覆盖送别、敬慕、思念、田园相聚几种阅读情境；同时包含地名明确、只出现大区域、无法定位三种资料状态。地图与星图可以接受这些差异，不应要求每首作品必须绑定精确地点、每个故事必须凑出具名关系。

## 唐诗单组与唐宋两组：编辑建议

| 选择 | 可优先回答的问题 | 编辑代价 |
| --- | --- | --- |
| 先用这四位唐诗候选 | 人物之间的作品关联是否好懂；读者能否从一首诗进入地点或另一位诗人 | 复用一组人物索引、异名和史料，较容易把每条关联核实清楚；仍需补充非送别作品，避免体验题材偏窄 |
| 唐宋同时各取一组 | 朝代切换、诗与词的排版和情境差异是否重要 | 需要额外核查宋代人物、词作版本与地点；两组可能自然分开，不能为“星河连贯”制造跨时代相识关系 |

建议先以唐诗单组讨论关联规则；若当前必须验证词的阅读体验，可另外加入极少量宋词作为独立阅读样本，不急于建立完整宋代关系网。这是编辑成本建议，不是最终范围决定；本轮尚未核查宋代候选。
