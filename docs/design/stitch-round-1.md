# Stitch 第一轮页面

> 历史记录，已由 R3 替代。旧版 HTML 与图片已于 2026-09-06 清理；当前入口见 [current-design.md](current-design.md)。下文描述当时的修改与限制。

项目：[诗词 · 页边入景](https://stitch.withgoogle.com/projects/15818295814883565750)。本轮沿用 D，A 保留备选。


- 今日：横排完整诗句、小页角画面、默认关闭的环境声；关联作品改为首批诗人范围内的作品。
- 探索：地图模式与地点结果；明确标注诗中之地。地图为设计示意，不代表已验证的地理位置。
- 诗人：李白作品、生平入口与人物联系。Stitch 编辑响应未可靠保存，直接校正导出 HTML 的关系出处及无依据卷号，并重新导入。
- 人物关系：四个诗人、稀疏关系线、作品依据面板。移除混入的图片。
- 诗集：三个整首作品收藏示例，缩小页角图片。

这是静态界面草稿。尚未实现真实导航、地图、音频、收藏、备份、生平详情或原生 iOS 页面。字体大小、触控区域及安全区需在原生实现中验证；不以 Stitch 的成功描述代替实际验收。

已检查下载截图、文字修订和本地预览。Stitch 部分生成结果未出现在项目画布，因此将选定 HTML 重新导入同一私有项目，标题以 01–05 标记本轮修订。保留旧稿供比较。
