# #18 轻环境声

原生增量采用共享 AudioStore、单个 AVAudioPlayer 和默认关闭的角落 AudioButton。未下载时明确标注「下载并播放缓水环境声」；完成摘要校验并原子落盘后才播放，之后使用 Application Support 中的离线文件。每次使用重验摘要，损坏或失败均可重试，不依赖阅读数据库。背景/系统音频打断停止，回到前台不自动恢复，下载中进入背景也不会下载后突然播放。所有页面复用一份播放状态。

仅加入一份许可明确的真实溪水录音，来源、原件摘要、处理过程和产物摘要见 `service/media/README.md`。素材说明在图标长按菜单，可访问名称区分下载、播放与停止。复用个人服务的钥匙串连接；服务仅允许已知声音的精确路径，鉴权与内容更新共用，Docker 随附已转换 WAV。

测试覆盖未完成/损坏/重启缓存、失败后重试、默认关闭、切换停止前声、播放失败清理，以及实际 HTTP 鉴权、路径白名单、真实 PCM 内容与摘要。Linux 已通过 service unittest；Swift 编译/测试交由 Mac 集成。

原型 HTML、静态导入和 R3 截图未变，此为原生实现而非原型验收。必须在实体 iPhone 试听循环接缝、突然噪声、停止、切换阅读页面和离线失败时正文可读；目前这些验收仍待完成。一个场景意味着没有第二种声音可选择，播放层的切换约束由测试验证。

集成：将 `AudioStore.swift`、`AudioButton.swift` 加入 Xcode target，在阅读页角使用 `AudioButton()`；不用新增设置入口。Swift Package 自动包含 `AmbientAudio.swift`。
