# #15 生平路线

原生诗人页可进入生平路线。随包 11 个节点在首次运行时写入 SQLite，后续离线重启从安装库读取。时间顺序为史籍支持的阶段序号，非臆造公历年；辋川生活独立放在「时间先后未定」。年号、范围和不同记载原样以短说明呈现，出处与不确定性按需展开。

内容依据为预先核查的《旧唐书》卷190下及《新唐书》卷201、202、203固定转录版本；每条均存来源版本链接、事实定位和许可说明。节点概述为项目独立表述。保留王维进士纪年精度差异、杜甫拾遗官名转录分歧、李白判流夜郎不等于抵达等边界。不采纳有争议死年，也不推算未经核对的出生年。仍需集成人工复核史籍与转录；结构测试不能证明史实。

当前节点均无配诗，因为已核查资料尚不足以给具体作品定年或认定事件因果。模型和界面分别支持「对应作品」及「同期作品」，后者明确提示时间相近不代表因事件而作；每个关联另存证据。缺失作品显示空态；已安装作品通过共享 ReadingDestination 进入阅读。

真实临时 SQLite 测试覆盖顺序、未定时间分区、重启持久化、空诗人、无配诗、证据保留和同期作品语义，使用明确标识的测试夹具验证作品读取后路线不变。UI 测试覆盖生平入口、离线来源展开及返回诗人位置；实际关联作品的导航使用现有共享阅读栈，种子无关联故未伪造史实来完成 UI 测试。

Linux 无 Swift 工具链，本分支仅完成 JSON 解析与 git diff --check；Swift 测试、iOS 编译及真机导航由集成验证。HTML 原型、Stitch 元数据与图片未变；本记录仅描述原生增量。
