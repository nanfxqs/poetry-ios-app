# 持久收藏与诗集（#11）

原生应用层新增 `saveFavorite`、`removeFavorite`、`isFavorite`、`favoritePoems(search:)`。SQLite 独立收藏表使用稳定作品标识和完整作品快照，不依赖内容表外键；后续内容下架不删除收藏。重复收藏保留原收藏顺序，取消后再收藏排至最前，顺序使用单调序号而非设备时钟。

`CollectionStore` 是根界面共享的可观察状态，收藏写入成功后再刷新所有页面。诗集按最近收藏排列，可搜标题、作者与诗句，并显示总数、空态返回今日和取消收藏操作。阅读导航保存作品值，不以收藏行的存在决定阅读页是否存在，因此取消收藏不退出阅读。

自动化用例位于 `CollectionTests.swift`：真实临时 SQLite 验证跨应用入口一致、重新打开、重复写入、取消持久化、排序、收藏内搜索与独立内容快照。Linux 环境无 Swift 工具链，本分支未运行 Swift 测试；由主分支在 Mac 执行编译及测试。

真机仍需核验：从今日收藏后立即切换诗集；在诗集阅读页取消后保留阅读位置；退出重开后状态一致；大字号搜索及取消操作。HTML 原型未改动，其页面内收藏演示不代表原生验收。根导航接入、Xcode 编译与真机结果由规格整合记录统一维护。
