# 搜索与分组标签（#12）

原生探索入口使用本地作品与编辑标签，支持标题、诗句、诗人关键词，以及朝代／诗人／意象／情绪／题材。组间取交集、组内取并集，默认折叠标签分组，已选条件单独展示，可逐项移除或清空。空结果保留条件并提供展开筛选入口。查询不依赖地点资料，未知地点作品仍可检索。

`ExplorationState` 保存关键词、分组选择与可见作品标识；`PoetryApplication` 经真实 SQLite 存取该状态。SwiftUI 将列表滚动位置绑定到状态，阅读使用当前探索 NavigationStack，返回保留查询上下文。

应用层测试覆盖组间／组内组合、标题／诗句／诗人搜索、未知地点、空结果保留与移除、读诗及重启后的上下文恢复。实际导航返回的滚动位置、大字号、折叠交互和真机离线行为仍须设备验收；应用层测试不替代该验收。本次新增原生功能，没有变更 R3 HTML、静态导入稿或高清图。

集成：将 `ExploreView(application:)` 放入探索 NavigationStack，Xcode Sources 加入 `ExploreView.swift`。阅读目标应接入统一阅读详情，以共享收藏等后续功能。标签来自 #10 的 `PoetryTags.bundled`；本模块没有为缺少标签的作品编造分类。
