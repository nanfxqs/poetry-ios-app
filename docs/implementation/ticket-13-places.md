# #13 地点地图与离线列表

原生探索复用作品搜索和全部分组标签查询，地点结果来自本地 SQLite 的 places 与 place_associations。关联类别单独存储；诗文证据与现代地理来源分开。地点点选只筛选当前作品，取消恢复原查询。阅读 push 返回保留地点选择、类别、地图镜头及原有列表位置。地图开关只影响底图；离线地点列表始终保留，不调用定位或地理编码。

当前仅有《黄鹤楼送孟浩然之广陵》的黄鹤楼／扬州诗中之地关联。扬州采用中国天气网江苏站 2014 年公开经纬度范围，矩形仅用于现代区域示意；其中心是推导的文字标签锚点，不显示精确地点钉。黄鹤楼显示异址重建说明，无核实数字坐标故不画图钉。每个地点展开可查看关联原文依据与地理来源链接。没有写作地数据，不从籍贯或远行方向推导。没有关联的作品始终可搜索阅读。

MapKit 为实际底图；底图失败无须检测或等待，可随时关闭地图使用同一份本地地点和作品。未实现自动网络错误横幅。区域地图只能认地方，不代表唐代边界、实测行程或写作坐标。

测试：新增 SQLite 行为测试覆盖地点类别、来源、区域精度、未知坐标、共享查询标签、重启离线结果与无地点可读；UI 测试覆盖离线地点点选、阅读返回与筛选保留。Linux 无 Swift 工具链，Swift 编译与测试交由主分支 Mac 集成。真机底图在线／断网、地图点选及返回仍须实际执行，不能以测试代码存在视为完成验收。HTML 原型、导入稿与高清图均未修改；这是原生功能增量，主分支统一同步当前状态文档。
