# 诗人概要与作品入口（#14）

原生新增四位诗人的有来源概要。`poets.json` 与作品一起离线安装至 SQLite，重启继续使用已安装资料；概要、来源标题、许可及资料边界可离线查看，外部史书链接明确标为需联网。资料依据固定版本《新唐书》卷 201、202、203，概要由项目独立编写，未引入现代传记原文。未核定的出生地、卒年与年谱不补造。

`PoetryApplication.poetOverview(id:)` 用稳定 `poetID` 查询本地已收录作品，展示收录数量及“非完整全集”。未知人物仍返回同标识作品，并明确显示资料缺失；无作品另有空态。`PoetView(application:poetID:)` 在当前导航栈进入 `ReadingDestination(application:poem:)`，返回保持来源页面。阅读作者与探索入口、Xcode 文件注册由集成步骤接入。生平与关系交给 #15/#16，不预先显示伪功能。

应用层测试覆盖四位诗人的资料与归属、离线重启、同名不同标识、未知人物及零作品。Linux 无 Swift 工具链；编译、应用层执行和 UI 往返验证由 Mac/实体设备集成执行，本提交未声称验收通过。HTML 原型与 R3 视觉规范未改变。
